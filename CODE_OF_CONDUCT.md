# Code of Conduct

## Our Standards

Co-Scientist is an open research software project. Contributors, maintainers, and users are expected to keep discussion respectful, specific, and focused on improving the project.

Examples of encouraged behavior:

- Use clear, constructive technical feedback.
- Assume mistakes can be corrected when there is no evidence of bad faith.
- Respect different levels of experience and different research backgrounds.
- Keep security reports, credentials, private research notes, and unpublished manuscript content out of public issues and pull requests.

Examples of unacceptable behavior:

- Harassment, insults, threats, or discriminatory language.
- Repeated off-topic disruption after maintainers ask for focus.
- Publishing private information without consent.
- Pressuring maintainers or contributors to disclose private credentials, unpublished research, or private vulnerability details.

## Scope

This code of conduct applies to project spaces, including issues, pull requests, discussions, documentation, examples, and community channels associated with this repository.

## Reporting

Report conduct concerns to the repository maintainers through the GitHub repository owner profile. Report suspected security vulnerabilities through the private process described in `SECURITY.md`, not through public issues.

Maintainers may remove content, close issues or pull requests, limit participation, or block accounts when behavior harms the project community or puts users at risk.

## Attribution

This policy is inspired by common open source community conduct policies, including the Contributor Covenant, but is written specifically for this project.
